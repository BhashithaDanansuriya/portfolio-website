Task Management System

Full-Stack Collaborative Task Management Web Application

A full-stack web application designed to help teams create, assign, manage, and track tasks efficiently, with role-based access control and real-time notifications.

Project Overview

The Task Management System is a full-stack web application developed to help teams organize, assign, and monitor tasks efficiently. The system supports multiple user roles and provides features such as task management, deadlines, priorities, progress tracking, comments, attachments, and real-time notifications.

The project was developed as a group assignment, with a focus on building a secure, scalable, and collaborative task management platform.

How the System Works

Login → Authentication → Role Verification → Dashboard → Task Management → Real-Time Updates

  1. Administrator - Manages users, roles, and system configuration.
  2. Project Manager - Creates and manages projects and tasks, assigns tasks, sets priorities and deadlines, and monitors progress.
  3. Collaborator - Views assigned tasks, updates task status, and contributes comments or attachments.
