TimeKids Preschool Management System

Individual System Development Project | Ongoing

Introduce TimeKids

The TimeKids Preschool Management System is an individual project I am currently working on to transform the preschool's existing manual processes into a centralized digital management system.

The system is being developed in collaboration with the principal of TimeKids Preschool, E.K.S.L. Edirisinghe, to improve the efficiency and organization of day-to-day activities.

Goals & Key Activities

The system aims to digitalize the following key activities:

  1. New Student Registration
  2. Monthly Fee Collection
  3. Attendance Tracking
  4. Parent Communication
  5. Assignment Management
  6. Extracurricular Activity Coordination

Project Status

Through this project, I am developing a practical solution to reduce manual work and improve the overall management of preschool activities. The project is ongoing and will continue to be improved based on user feedback from the preschool staff.
